Today at a glance

We set up the backend with the configuration supplied for the project, made sure the credentials are not tracked by Git, added working filters to the attendance history page, and wrote this handover note in both HTML and Word so the work is easy to review.

Code already in place

Most of the application was built before today. The frontend is a React app with staff clock in/out screens, a QR scanner, an admin dashboard, and an attendance history page with role-based columns and a CSV export control. Sign-in and user roles come from Firebase Auth.

The backend is a small Node/Express server. It already handles cross origin requests, JSON data, errors and a health check. The Google Sheets and Firebase Admin features are the next pieces to connect.

The intended flow is: staff sign in with Firebase, the frontend sends the sign-in token with each request, the backend checks that token, and attendance is read from and written to the company spreadsheet. Today's work added the secure configuration the backend needs for those connections ÔÇö no screens or endpoints were changed.

What we added

  • A fuller backend example file listing every setting that needs to be provided, with dummy values instead of real ones.
  • A filter form on the attendance history page: date range, status, and a search box for name, email or department.
  • A reset control that clears every filter and reloads the full history, plus a clear option in the "no matches" message.
  • This daily work log in two formats: an HTML file to view in the browser and a Word document to edit or print.

  • The history table now shows only the filtered records, with a clear reset button and a friendly message when nothing matches.
