Integration notes

Endpoint

GET {VITE_API_URL}/api/v1/attendance/history. Default base URL is http://localhost:5000.

Token

auth.currentUser.getIdToken() is preferred. If nobody is signed in, a stored token is used (firebaseIdToken, idToken, authToken, token). Sent as a bearer token.

Role rules

role === 'admin' shows admin columns. Staff, unknown or invalid tokens hide them. The backend still verifies the token and enforces RBAC.

Response shapes

Accepts a bare array or history, records, results, attendance, data wrappers.

Security note: decoding a JWT in the browser only selects which columns to show. It is not authorisation. Firebase verification and role checks must remain server-side.

Analytics from the supplied snippet is optional and was left out to avoid tracking during tests. It can be added later if required.

UI states

State Rendering
Loading Shared Loader — “Loading attendance history…” — centred in the records card; refresh is disabled.
Empty Icon, “No attendance records yet”, role-specific copy and a Refresh button.
Error Shared ErrorMessage using safe mapped copy plus a Try again action; raw errors are never shown.
Loaded Responsive table with record count, statuses and admin-only columns when applicable.
Exporting The Export CSV button and both date inputs are disabled, and the button shows a labelled inline Loader.
Export feedback Inline record count on success or safe error copy; a reversed date range is rejected before the export starts.

Admin dashboard — CSV export control

The Dashboard page itself is being built by teammates, so no route or page was changed. ExportCsvControl is self-contained and exports client-side from the records the dashboard already has; no backend endpoint is required. 

import { ExportCsvControl } from './components';

<ExportCsvControl records={attendanceRecords} />

Date filter

Start and end date inputs sit next to the button. The range is inclusive; a reversed range shows an inline error and blocks the export.

Loading state

On click the button and both inputs are disabled, and the button shows a labelled inline Loader. Double submits are blocked until the export finishes.

CSV output

Date, Staff, Email, Department, Clock in, Clock out, Hours and Status by default. Values with commas, quotes or newlines are escaped correctly and the file downloads as .csv with a UTF-8 BOM.

Customising

Optional props: columns, filename, label, loadingLabel, minLoadingMs and onExport to replace the built-in download.

Design source: styled from L.C Admin/dashboard.html on the desktop (dark #0f172a button, 6px radius, 12px label and gray-bordered date inputs). The private Slack/Figma link was not accessible. The dashboard page itself was not created or changed here — it remains its owner's work.
