## Requirements
- Provide a clock-out API endpoint.
- Verify Firebase authentication.
- Validate employee eligibility and attendance status.
- Generate server-side clock-out timestamps.
- Save attendance data to Google Sheets.
- Prevent duplicate clock-outs.
- Return appropriate success and error responses.

## Acceptance Criteria
- [ ] Valid clock-out requests succeed.
- [ ] Invalid authentication is rejected.
- [ ] Inactive employees cannot clock out.
- [ ] Employees without a prior clock-in cannot clock out.
- [ ] Duplicate clock-out requests are prevented.
- [ ] Timestamp is generated by the server.
- [ ] Employee ID, Firebase UID and time are saved correctly.
- [ ] Attendance status changes to OUT.
- [ ] API responses match the agreed contract.

## Dependencies
- Firebase authentication.
- Google Sheets integration.
- Team 2 clock-in backend.
- Shared attendance and API contract.
