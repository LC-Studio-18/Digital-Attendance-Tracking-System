# ST-02 - Build the Loader, ErrorMessage and SuccessMessage Components

## Information

- Ticket ID: S1-16
- Assigned developer: Rasool Federicks
- Current QA status: Pass

## Objective

- Build reusable `Loader`, `ErrorMessage`, and `SuccessMessage` React components for login, clock-in/out, and dashboard loading states with compliant copy, icons, and accessibility support.

## Acceptance Criteria

- [x] Loading indicator appears with a visible label and disables action buttons while requests are in progress.
- [x] Success message displays only after confirmation with specific details, icon, and dismiss/auto-hide support.
- [x] Failed login, expired session (401), permission error (403), duplicate action (409), server error (500), and offline states show approved user-friendly copy without raw error text or stack traces.
- [x] Failed data loads (500 and offline) include a functional "Try again" button.
- [x] Messages are readable on mobile (360px), accessible (icon + text, screen-reader friendly), and reusable across screens.
