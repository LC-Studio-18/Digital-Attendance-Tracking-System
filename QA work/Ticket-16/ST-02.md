## Objective
- Build standalone reusable `Loader` component and wrapper pages (`LoginLoader`, `AttendanceLoader`, `DashboardLoader`) with modal overlays, text descriptions, and disabled button states to handle asynchronous operations.

## Acceptance Criteria
- [x] Reusable `Loader` component is implemented with support for inline (`small`/`medium`) and modal overlay (`large`) sizes.
- [x] Standalone loader pages (`LoginLoader`, `AttendanceLoader`, `DashboardLoader`) render accurate custom titles and descriptions.
- [ ] Loader components and button `disabled` lockouts are wired into live login, clock-in, clock-out, and dashboard screens.
